# Arbeitsweise für dieses Projekt

- Nach jeder fertigen, getesteten Änderung selbständig committen und auf `main` von `rarum-gif/Rarum` pushen – ohne extra nachzufragen. Der Inhaber schaut sich die neue Version direkt im Repository bzw. über Vercel an.
- Vor dem Push: `npx tsc --noEmit`, `npm test` und `npm run build` müssen durchlaufen.
- Kommunikation mit dem Inhaber auf Deutsch, kurz und ohne Fachjargon.
